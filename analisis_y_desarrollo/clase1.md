# Resumen Clase 1

# Análisis y Diseño de Software 
## Ciclo de vida del Software: 
Este es el proceso de pensar, estructurar y planificar el sistema digital antes de crear el código, ya que esto ayuda a prevenir errores que se puedan presentar en el código. 
## Esta se estructura por:  
Análisis de requerimientos: Enfocado en entender el problema y su objetivo es definir qué se va a hacer o construir. 
Diseño: Este define como se va a construir el sistema, como será su arquitectura, los componentes y la interfaz del usuario. 
Implementación: Se escribe el código basado en el diseño. 
Pruebas y análisis: Se hace una verificación del código para asegurarse de que el programa funciona correctamente y no presenta errores. 
Despliegue: Se entrega el producto al cliente para su uso real. 
Mantenimiento: Se corrigen errores nuevos y se añaden mejoras. 
Metodologías de Desarrollo 
# Metodología Estructurada 
Tradicionales:  En esta se hace una planificación completa y detalla para sistemas complejos y críticos en donde no se puede fallar. En esto se incluye el Modelo Cascada (fases secuenciales), Modelo en V (énfasis en pruebas) y el Modelo Espiral (basado en gestión de riegos). 
# Metodología Ágiles 
Aquí hay una adaptación constante, una colaboración entre cliente y software. Utilizando interacciones.  
## Requerimientos 
Estos son condiciones del sistema que se deben de cumplir, están en:  
Funcionales, que vendrían siendo acciones específicas que el sistema debe de realizar, y No Funcionales, que son características de calidad o restricción. 
Para que esto sea efectivo debe de usarse SMART, ya que es Especifico (Specific), Medible (Measurable), Alcanzable (Achieavle), Relevante (Relevant) y con un Plazo definido (Time-bound). 
Estas se obtienen mediante técnicas de elicitación como: entrevista, encuesta, observación, talleres, análisis de documentos y prototipos.
