# Resumen: Diseño de Software

El diseño de software es la etapa en la que los requerimientos se transforman en una solución técnica que servirá de guía para el desarrollo. Mientras el análisis se enfoca en identificar qué necesita el usuario, el diseño define cómo se implementará la solución.

## El diseño se divide en cuatro niveles principales:

* **Diseño arquitectónico:** estructura general del sistema y sus módulos.
* **Diseño de interfaces:** interacción con usuarios y sistemas externos.
* **Diseño de componentes:** lógica interna, algoritmos y clases.
* **Diseño de datos:** organización y almacenamiento de la información.

Para lograr un software de calidad se aplican principios como la **abstracción**, **modularidad**, **encapsulamiento**, **alta cohesión** y **bajo acoplamiento**, que facilitan el mantenimiento y la escalabilidad.

Entre las arquitecturas más utilizadas se encuentran la **arquitectura en capas**, el modelo **cliente-servidor** y los **microservicios**. Una buena elección arquitectónica es clave para el rendimiento y crecimiento del sistema.

Finalmente, el módulo incluye actividades para comprender las diferencias entre análisis y diseño, aplicar los conceptos de cohesión y acoplamiento, e identificar problemas comunes en la estructura de software.
